How these were made. Each session was written by a language model{% if model %} ({{ model }}){% endif %} from a prompt holding the athlete profile, the block plan for that week, competition-lift volume targets and passages retrieved for that session from an ingested library of weightlifting books, papers and coaching articles. A validator checks every session (rep counts per intensity zone, intensity ceilings, the avoid list, complexes) before it is saved; failed sessions are regenerated with the errors attached.
